# ImageShare 0.1.0 prerelease

ImageShare 0.1.0 is the first public prerelease of a privacy-first Android image sharing tool. It processes images on your device, with no account, analytics, or network permission required.

## Highlights

- Convert images to JPEG, PNG, or WebP and use presets for smaller files, better quality, social uploads, or email attachments.
- Strip metadata by default, including location data, before sharing.
- Share one or many images from Android's photo picker, document picker, or another app's Share menu.
- Use smart sharing to surface your most-used destinations, with a full alphabetical fallback.
- Resize images with aspect-ratio protection, target-size encoding, and transparent-image handling.
- Keep longer processing jobs running in the background and reuse recent images when their Android permission allows it.

## For developers

The included Transform API lets compatible Android apps request ImageShare processing through IPC. The API's implementation is evolving; see the [integration guide](../transform-api/integration-guide.md) and [threat model](../transform-api/threat-model.md) before adopting it.

## Installation and verification

Download `app-release.apk` from this release and compare its SHA-256 checksum with `app-release.apk.sha256` before installing. The APK is signed with the project's release key.

This prerelease is distributed through GitHub Releases.
