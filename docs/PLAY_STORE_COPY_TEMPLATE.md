## Full description (4000 char max)

ImageShare helps you prepare photos before you send them. Resize, compress, convert, and strip metadata on your Android device without cloud uploads, accounts, ads, analytics, or tracking.

Key features:

- Fast presets for common sharing needs.
- Batch processing for multiple images.
- Target file size mode for upload limits.
- Custom dimensions with aspect-ratio lock.
- Long-edge, percentage, exact-size, and original-size options.
- Metadata stripping for GPS, camera serial numbers, maker notes, and other EXIF fields.
- Persistable recents for quick repeat workflows.
- Modern Material 3 interface built for Android 10 and newer.

Privacy-first by design:

- No INTERNET permission.
- No analytics or telemetry.
- No ads.
- No broad media-library permission.
- Originals remain in their original location.
- Processed copies are kept only in app-private cache until you save or share them.
- Open source under the GNU GPL v3 license.

Format support:

- Input: JPEG, PNG, HEIF, WebP, GIF, AVIF.
- Output: JPEG, PNG, and WebP.

For power users:

- EXIF stripping reduces accidental location and device metadata sharing.
- Alpha-aware handling preserves transparency where the selected output format supports it.
- Background batches can continue with foreground progress notifications.
- Presets make repeat sharing workflows faster and more predictable.

Open source:

https://github.com/adsamcik/ImageShare

ImageShare is built for people who want smaller, cleaner images without sending private photos through another service. Choose a photo, pick a preset, process locally, and share with confidence.
